# Prism
Prism is a local developer assistant with a live NVIDIA model, real perception, and Docker-isolated command execution. It chooses the minimum screen, terminal, or process context needed for each task. Persistent server access settings allow automatic context and default file modification, dependency installation, and command networking to ask first. Access requests can be minimized, closed, and reopened; task grants expire with the task. Revocation stops an active task using that capability. Users separately review and approve exact patches and argv commands. Shared Python schemas generate frontend types. No secrets belong in the browser. There is no demo runtime.
