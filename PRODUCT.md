# Prism
Member 3 delivers the local frontend for an approval-gated developer assistant. Users submit a command, inspect captured context and an analysis, review proposed patches and argv commands, and explicitly approve or reject execution. One task may run at a time. Member 2 owns shared/schemas.py and the backend OpenAPI contract. The frontend uses generated types and includes an isolated browser demo plus an endpoint contract script. No backend secrets belong in this project.
