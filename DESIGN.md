# Task workspace
Mode: Operate. A quiet daylight workspace for reviewing potentially consequential code changes. Warm paper (#f5f4ef), white work surfaces, dark ink (#202824), and forest green (#275e47) for primary actions. Amber marks pending approval; red marks failures or policy denials. System sans for controls and prose; monospace only for code and identifiers. A persistent narrow navigation rail, generous main reading area, and a compact context column establish hierarchy. At narrow widths columns stack and navigation becomes a top bar. Explicit text accompanies every state; focus outlines and reduced-motion support are required. Code diffs retain whitespace and scroll within their region.
